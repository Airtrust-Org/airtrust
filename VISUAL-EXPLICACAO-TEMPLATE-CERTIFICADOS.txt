[1] Frontend clica "Gerar Certificado"
    ↓
[2] POST /api/qualificacoes/historico/:id/certificados/gerar
    ↓
[3] Backend busca:
    • Dados do funcionário (nome, CPF, matrícula)
    • Qualificação (nome, código, categoria)
    • Empresa (ID)
    ↓
[4] ✅ Busca template em certificados_templates
    WHERE empresa_id = :empresaId AND ativo = 1
    ↓
[5] Detecta se é JSON estruturado
    ↓
[6] Converte JSON → HTML com cores e layout da empresa
    ↓
[7] Substitui placeholders:
    {{funcionario_nome}} → "João da Silva"
    {{funcionario_cpf}} → "123.456.789-00"
    {{qualificacao_nome}} → "Piloto Privado"
    {{data_conclusao}} → "15/01/2024"
    ↓
[8] Envia HTML para Cloudflare Browser Rendering API
    ↓
[9] PDF gerado com layout profissional
    ↓
[10] Upload em R2 (Cloudflare Storage)
     ↓
[11] Indexação em D1 (banco de dados)
     ↓
[12] Frontend recebe: { success: true, id: 789, ... }
     ↓
[13] Usuário clica "Download"
     ↓
[14] ✅ PDF baixado com template da empresa aplicado


🧪 COMO VERIFICAR SE ESTÁ FUNCIONANDO
════════════════════════════════════════════════════════════════════════

1. Verifique se existem templates no banco:
   SELECT COUNT(*) FROM certificados_templates 
   WHERE empresa_id = 1 AND ativo = 1;
   
   Esperado: >= 1 template

2. Gere um certificado de teste:
   curl -X POST https://api.airtrust.com.br/api/qualificacoes/historico/123/certificados/gerar \
     -H "Authorization: Bearer $TOKEN"

3. Verifique os logs:
   📄 [GERAR PDF] Buscando template em certificados_templates...
   📄 [GERAR PDF] ✅ Template encontrado: "Template Padrão Aviação"
   📄 [GERAR PDF] Template é JSON estruturado, convertendo para HTML...
   📄 [GERAR PDF] ✅ Usando Cloudflare Browser Rendering com template HTML
   ✅ [GERAR PDF] PDF gerado via Browser Rendering: 45234 bytes

4. Baixe o certificado:
   curl -X GET https://api.airtrust.com.br/api/pasta-virtual/stream/789 \
     -H "Authorization: Bearer $TOKEN" \
     -o certificado.pdf

5. Abra o PDF e verifique:
   ✅ Logo da empresa no topo
   ✅ Cores conforme template (primária, secundária, destaque)
   ✅ Nome do funcionário em destaque
   ✅ Qualificação e datas corretas
   ✅ Layout profissional


📋 TABELA DE TEMPLATES
════════════════════════════════════════════════════════════════════════

certificados_templates
├─ id (INTEGER PK)
├─ empresa_id (FK → empresas)
├─ nome VARCHAR(100)           ← Nome do template
├─ descricao TEXT
├─ tipo VARCHAR(50)            ← PADRAO, TREINAMENTO, CURSO, CUSTOM
├─ template_json TEXT          ← JSON estruturado com elementos
├─ logo_url TEXT               ← URL da logo
├─ ativo BOOLEAN               ← Se está ativo
├─ padrao BOOLEAN              ← Se é template padrão da empresa
├─ criado_em TIMESTAMP
└─ ... (cores, fontes, margens, etc.)

Índices:
- idx_templates_padrao: (empresa_id, padrao, ativo)
- idx_templates_tipo: (tipo, ativo)
