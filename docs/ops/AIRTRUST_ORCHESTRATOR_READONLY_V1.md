# AirTrust Orchestrator — V1 read-only

## Status

This is a **read-only event reconciler**, not a persistent autonomous AI agent or release manager.
It operates in GitHub Actions, independently of the owner's Mac. It has no AI model
credentials, GitHub write permission, Cloudflare permissions or release permission.

## Sources of truth

GitHub main ref, open issues, open PRs and the public Worker source SHA.
The script never infers CI PASS, environment approval or release from issue/PR metadata.
The event key is informational for provenance; durable exactly-once dispatch is NOT present.
All issue and PR descriptions remain in GitHub and are not copied to artifacts.

## Events

PR events, issue state changes, selected workflow completions, authorized issue #776
status command, manual workflow_dispatch and a daily missed-event reconciliation.
Runs use a serial concurrency group to avoid overlapping snapshot generation.

## Limitations before any agent execution

1. Configure scoped, non-interactive Codex/Gemini identity for an isolated runner
   (none is assumed to exist; never copy the personal chat session).
2. Add a durable claims/lease store or a GitHub App write protocol with CAS,
   expirations, dedup by issue/PR/HEAD/event, recovery and rate limits.
3. Implement per-domain branch/PR ownership and sandbox write permissions.
4. Validate untrusted PR payload handling, cost ceilings, retry limits and security.
5. Establish a separate human-reviewed release approval channel. Never let this
   workflow inherit deploy or migration credentials.
