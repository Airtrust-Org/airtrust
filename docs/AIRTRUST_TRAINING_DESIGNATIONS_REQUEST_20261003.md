# AirTrust — Checklist de Designações para Gestores

**Data:** 2026-10-03  
**Objetivo:** recolher somente as designações que realmente dependem de indicação nominal, mantendo os treinamentos amplos da matriz sem burocracia desnecessária.

## Como preencher

Cada gestor deve devolver apenas os nomes das pessoas efetivamente designadas para as funções abaixo. Não é necessário listar funcionários para treinamentos que já são obrigatórios por empresa, setor ou cargo.

Não enviar senhas, documentos pessoais, dados médicos ou outras informações sensíveis. Para implantação no AirTrust, o vínculo deve ser feito pelo funcionário já cadastrado no sistema.

## Não precisa devolver lista nominal para estes treinamentos

Pela decisão V4, **não solicitar designação individual** apenas para controlar aplicabilidade de:

- AVSEC Conscientização — toda a empresa;
- NR-06 — público amplo da matriz;
- NR-11 — Mecânicos e Auxiliares de Manutenção;
- NR-20 — público amplo aplicável do ambiente operacional/manutenção;
- NR-26 / Produtos Químicos / FDS — pessoal operacional;
- NR-35 — público de Manutenção já previsto na matriz;
- FDM EAD — somente pessoas formalmente designadas para a equipe/programa FDM/HFDM.

A ausência de nome em uma designação deve ser tratada como **“não informado / pendente de confirmação”**, e não como autorização para inferir o ocupante automaticamente.

## Regra de implantação no AirTrust

1. Receber a lista do gestor responsável.
2. Conferir que o funcionário pertence ao tenant correto.
3. Vincular a condição/designação pelo fluxo auditável do Compliance.
4. Não alterar histórico de qualificações para criar a designação.
5. Recalcular a matriz após as designações serem salvas.
6. Validar se as obrigações específicas apareceram somente para os ocupantes informados.
7. Preservar todas as obrigações amplas da matriz V4.
