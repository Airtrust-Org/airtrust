🔑 Criar Token Cloudflare

Siga os passos abaixo para criar um novo API Token com todas as permissões necessárias

1 Abra o Cloudflare Dashboard

Acesse o link abaixo e faça login:

2 Clique em "Create Token"

Na página de API Tokens, clique no botão verde "Create Token"

3 Selecione "Custom Token"

Você verá opções de templates. Clique em "Custom Token" (embaixo)

4 Configure as Permissões

Token Name:

airtrust-workers-d1-final

Permissions (marque exatamente estes):

  • Account - D1 - Edit
  • Account - D1 - Read
  • Account - Cloudflare Workers Scripts - Edit
  • Account - Cloudflare Workers Scripts - Read
  • Account - Cloudflare Workers KV - Write
  • Account - Cloudflare Workers KV - Read
  • Account - Cloudflare Workers R2 Storage - Edit
  • Account - Cloudflare Workers R2 Storage - Read
  • Account - Cloudflare Workers Tail - Read
  • Account - Account Settings - Read
