# 00_INBOX

Pasta de captura rápida. Notas aqui são temporárias e devem ser triadas.

## Regras
- Qualquer ideia, observação ou nota bruta vai aqui
- Durante o triage (idealmente a cada 1-2 semanas):
  - Se é sobre um módulo → mover para `02_MODULOS/` com o template correto
  - Se é dívida técnica → criar nota em `07_RISCOS_E_DIVIDA_TECNICA/`
  - Se é prompt útil → formatar em `04_PROMPTS_MESTRES/`
  - Se é decisão → criar ADR em `03_DECISOES_ADR/`
  - Se é regulatório → mover para `09_REGULATORIO_ANAC/`
  - Se é obsoleto → `99_ARQUIVO/`
